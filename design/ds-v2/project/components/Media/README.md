`Media` — відео `.video` і галерея зображень `.gallery` у статті, без автопрогравання й без каруселі.

**Коли брати.** Відео — для руху, який не передати фото: паяння, звук мотора, поведінка в польоті. Галерея — кілька фото одного предмета чи етапів однієї роботи. Одне зображення — це `Image`.

**Що дає автор.** У MDX: `<Video src poster title duration transcript />` і `<Gallery>` з `<Photo src alt caption />`. Тривалість і розмір файла збірка пише в підпис: «2 хв 40 с · 18 МБ». `transcript` — посилання на текстовий опис кроків. Доки файла немає, на його місці плита `--plate` з написом «Відео ще не додано».

**Стани.** Відео: заставка з кнопкою `.video-play`, наведення, фокус (кільце довкола всього кадру), помилка `.pic-err` із посиланням на текстовий опис. Файл вантажиться лише після натискання; далі працюють рідні елементи керування `<video controls>`. Галерея — сітка від 160px на колонку; фото з підписом є посиланням на повний розмір і має наведення та фокус.

**Токени.** `--plate`, `--on-plate`, `--line`, `--line-control`, `--radius-lg`, `--radius-pill`, `--text`, `--text-2`, `--fill`, `--danger`, `--olive-ink`, `--space-6`, `--space-8`, `--space-12`, `--space-16`.

**Правила.**
- Можна: підпис під кожним фото й текстовий опис до кожного відео.
- Можна: вказувати розмір файла — у полі трафік рахують.
- Не можна: автопрогравання, звук без дії читача, зациклені ролики.
- Не можна: карусель, що гортається сама чи ховає фото за стрілками.
