`.tbl.pinout` — таблиця розпіновки: вивід у mono, його функція й примітка, куди він іде.

**Коли брати.** Для роз’єму, майданчиків плати чи джгута, де читач паяє за таблицею: приймач до польотного контролера, балансувальний роз’єм, порт телеметрії. Порівняння характеристик — звичайна `Table`. Якщо є креслення плати, поставте поруч `Figure` з тими самими позначеннями.

**Що дає автор.** У MDX: `<PinoutTable caption="Приймач ELRS до польотного контролера" columns={[…]} rows={[…]} />`; рядок — вивід, функція, примітка. Позначення виводу пишіть так, як воно надруковане на платі: `5V`, `GND`, `TX`. Проп `hot` виділяє рядок, про який ідеться в тексті.

**Стани.** Звичайний рядок; виділений `tr.hot` на `--fill`; порожній стан — речення `.empty` з посиланням на документацію виробника. На вузькому екрані таблиця тримає ширину 480px і прокручується в `.tbl-wrap`, який має `tabindex="0"` і назву для читача екрана.

**Токени.** `--font-mark` (колонка виводів), `--line`, `--line-strong`, `--text`, `--text-2` (шапка й підпис), `--fill`, `--space-6`, `--space-8`, `--space-12`, `--space-24`.

**Правила.**
- Можна: колір дроту словом у примітці: «червоний».
- Можна: підпис `caption`, що називає обидва кінці з’єднання.
- Не можна: кольорові клітинки чи крапки як єдине позначення дроту.
- Не можна: mono для функції та примітки; розпіновка з пам’яті, не звірена зі схемою плати.
