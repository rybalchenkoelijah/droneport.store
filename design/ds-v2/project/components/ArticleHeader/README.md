`.art-head` — шапка статті бази знань: назва, короткий вступ, дата оновлення, час читання й теги.

**Коли брати.** Один раз угорі кожної статті, одразу під хлібними крихтами `Crumbs`. У списках статей назву й час читання показує `ListItem`.

**Що дає автор.** Поля на початку файла MDX: `title`, `lead` (необов’язковий, одне-два речення), `updated` у форматі `2026-11-18`, `tags`. Час читання збірка рахує за кількістю слів. Дата виводиться як «Оновлено 18.11.2026» в елементі `<time datetime>`; теги — список посилань `.tag` на добірки статей.

**Стани.** Тег: звичайний (`--fill`, текст `--text-2`), наведення (`--fill-strong`, `--text`), фокус. Шапка без вступу й без тегів стискається до назви та рядка метаданих. Довга назва переноситься з вирівняними рядками. Завантаження — дві смужки `.skel`. На телефоні тег заввишки 44px.

**Токени.** Стилі `title`, `body`, `caption`; `--text`, `--text-2`, `--fill`, `--fill-strong`, `--radius-sm`, `--space-2`, `--space-6`, `--space-8`, `--space-12`, `--space-24`, `--control-touch`.

**Правила.**
- Можна: назва, що відповідає на запит читача: «Як підібрати LiPo до моторів 2207».
- Можна: до п’яти тегів, кожен — іменник або маркування.
- Не можна: надзаголовок чи назва розділу над назвою статті.
- Не можна: автор, версія, кількість переглядів, дата створення замість дати оновлення.
