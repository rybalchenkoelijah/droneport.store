`blockquote` у `.prose` — цитата: чужі слова з відступом і знаком « на полі, без кольорової планки.

**Коли брати.** Для дослівно наведеного тексту: рядок з інструкції виробника, правило з пам’ятки, відповідь інженера. Власне зауваження автора — це `Callout`, а не цитата.

**Що дає автор.** У Markdown — рядки, що починаються з `>`. Джерело — останній рядок, який збірка загортає у `<footer>`; назва документа йде в `<cite>`. Зовнішні лапки не набирайте: знак « на полі ставить система, і читач екрана його не озвучує.

**Стани.** Стану взаємодії немає. Варіанти: з джерелом, без джерела, на кілька абзаців.

**Токени.** `--text` (текст цитати), `--text-2` (знак і джерело), `--space-4`, `--space-12`, `--space-24` (відступ ліворуч).

**Правила.**
- Можна: скоротити цитату, позначивши пропуск «[…]».
- Можна: вказати джерело й дату документа.
- Не можна: кольорова планка збоку, тло чи курсив на весь блок.
- Не можна: цитата без дослівного джерела як спосіб виділити власну думку.
