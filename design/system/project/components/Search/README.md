Поле пошуку `.search` шукає товари й статті за назвою, артикулом або параметром.

Використовуйте один раз на екрані, зазвичай у нижній панелі чи шапці каталогу. Для звичайних даних форми беріть `.fld`.

Споживач дає `input` з `aria-label` і плейсхолдером («Пошук: назва, артикул або параметр»), іконку пошуку, кнопку `.go` з `aria-label="Шукати"` і, за потреби, рядок `.status` та `kbd` для підказки клавіш. Результати мають бути в зоні `aria-live`.

Стани: порожнє з плейсхолдером, заповнене, фокус (кільце 2px `olive-ink` на всій смузі через `:focus-within`), `.go:disabled`, поки поле порожнє. Рядок `.status` повідомляє кількість і підказки клавіш; на екранах до 760px він схований.

Токени: `bg-raised`, `shadow-raised`, `radius-xl`, `line-strong`, `olive`, `on-olive`, `control`, `text-3`, `olive-ink`.

- Зберігайте введений запит, коли результатів немає, і пишіть, що спробувати далі.
- Не додавайте другу заповнену оливкову кнопку поруч із `.go`.
- Не ховайте `aria-label`: плейсхолдер його не замінює.
- Не вимикайте `.go` після введення тексту.
