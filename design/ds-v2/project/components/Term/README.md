`.term` — абревіатура на `<abbr>` з поясненням, яке відкривається наведенням, фокусом або дотиком.

**Коли брати.** Для скорочень, які знає не кожен читач: РЕБ, ESC, VTX, CRSF. При першій згадці в статті розшифруйте термін просто в тексті; `Term` потрібен для наступних згадок і для тих, хто відкрив статтю з середини. Маркування деталей (`XT60`, `6S`) — це `code`, а не термін.

**Що дає автор.** У MDX: `<Term>РЕБ</Term>`. Пояснення береться зі спільного словника сайту; проп `def` задає його для одного випадку. Збірка ставить `<abbr tabindex="0" aria-describedby="…">` і поруч `<span class="term-tip" role="tooltip">`. Клас `.end` вирівнює пояснення по правому краю, коли термін стоїть наприкінці рядка.

**Стани.** Звичайний — пунктирне підкреслення `--text-2`; наведення й фокус з клавіатури відкривають пояснення; дотик відкриває й закриває його; Esc ховає. Курсор можна перевести на саме пояснення — воно не зникає. Наведення й фокус працюють на CSS, дотик та Esc потребують скрипта сайту (зразок у прев’ю).

**Токени.** `--bg-raised`, `--shadow-raised`, `--line-strong`, `--text`, `--text-2`, `--radius-md`, `--space-2`, `--space-4`, `--space-8`, `--space-12`, `--olive-ink`.

**Правила.**
- Можна: пояснення одним реченням, спершу розшифрування.
- Можна: один і той самий текст пояснення в усіх статтях.
- Не можна: атрибут `title` — на дотик і з клавіатури він недоступний.
- Не можна: посилання, кнопки чи вимоги всередині пояснення.
