Спільні неідеальні стани: завантаження, порожній результат і рядок помилки.

**Коли брати.** `.skel` поки дані вантажаться; `.empty` коли списку немає; рядок помилки коли запит не вдався. Для помилки в полі форми є `.fld.err`.

**Що дає споживач.** Для завантаження: `.skel` у формі рядків списку, у контейнері з `role="status"`. Для порожнього: речення, яке каже, що робити далі. Для помилки: слово «Помилка», пояснення й дія «спробуйте ще раз».

**Стани.** `.skel` пульсує, а за `prefers-reduced-motion` стоїть. `.empty` має колір `--text-2`. Помилка: текст `--danger` з іконкою й словом, не лише кольором.

**Токени.** `--fill-strong`, `--radius-xs`, `--text-2`, `--danger`, `--space-8`, `--space-16`, `--dur-base`.

**Правила.**
- Роблять: порожній стан з наступним кроком: «Спробуйте коротший код».
- Роблять: форму скелета, що збігається з реальним рядком.
- Не роблять: спінер замість скелета на списках.
- Не роблять: помилку без слова й без дії.
