Кнопка-іконка `.ib` виконує дію без тексту: скопіювати артикул, закріпити, поділитися.

Використовуйте в смугах, рядках і панелях, де бракує місця. Якщо дія неочевидна або важлива, беріть `.btn` з текстом.

Споживач дає SVG-іконку `.icon` (у `.ib.sm` додайте `.icon.sm`) і обов'язково `aria-label` з дією, наприклад «Закріпити статтю». Для перемикача додайте `aria-pressed`.

Стани: звичайна, `:hover`, фокус (кільце 2px `olive-ink`), `[aria-pressed="true"]` (темніший фон), `:disabled`. Розмір `.ib` дорівнює `control` (28px), `.ib.sm` має 24px. Нижче 760px обидва ростуть до `control-touch` (44px).

Токени: `control`, `radius-md`, `radius-sm`, `icon`, `icon-sm`, `fill`, `fill-strong`, `text-2`, `text-3`, `olive-ink`.

- Завжди додавайте `aria-label`: іконка без назви не читається скрінрідером.
- Не показуйте натиснутий стан тільки кольором іконки: працює фон `fill-strong` і `aria-pressed`.
- Не робіть кілька однакових іконок поспіль без підказки.
- Не вживайте `.ib.sm` як основну дію на сторінці.
