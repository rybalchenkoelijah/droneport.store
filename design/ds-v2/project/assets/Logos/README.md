Логотип «Дронопорт»: коло кольору `brand` і назва, переведена в контури.

- `logo-mark.svg` — знак окремо, для значка сайту й місць до 32px.
- `logo-lockup.svg` — знак із назвою для світлого тла (`bg`, `bg-side`).
- `logo-lockup-dark.svg` — те саме для темного тла.

Колір знака однаковий в обох темах і не змінюється. Навколо логотипа лишайте вільне поле не менше висоти знака. Не розтягуйте, не перефарбовуйте, не ставте на фото. У верхній смузі лівої панелі стоять знак `logo-mark.svg` розміром `logo` і назва стилем `wordmark`, разом як одне посилання на головну. У вузьких місцях лишається сам знак.
