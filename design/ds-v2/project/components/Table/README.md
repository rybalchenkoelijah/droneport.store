`.tbl-wrap > .tbl` — таблиця для порівняння значень і специфікацій без зовнішньої рамки.

**Коли брати.** Для двох і більше вимірів: напруга за станом, характеристики мотора. Для одного значення вистачить рядка тексту.

**Що дає споживач.** `thead` із `th` (можна без нього), рядки `tr` і комірки `td`. Останній стовпець вирівнюється праворуч автоматично. Для чисел додайте `.num`.

**Стани.** Звичайний рядок. `td.k` — стовпець ключів у специфікації з двох колонок, кольору `--text-2`. `tr.hot` — виділений рядок із фоном `--fill`. Широка таблиця прокручується в `.tbl-wrap`.

**Токени.** `--line`, `--line-strong`, `--line-w`, `--text-2`, `--fill`, `--space-6`, `--space-8`, `--space-12`.

**Правила.**
- Роблять: лише нижня лінія в кожного рядка; зовнішньої рамки й вертикальних ліній немає.
- Роблять: одиниця в кожній комірці через нерозривний пробіл, кома як десятковий роздільник.
- Не роблять: смугасту заливку рядків.
- Не роблять: `tr.hot` більше ніж на одному рядку.
