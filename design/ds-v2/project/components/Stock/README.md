`.stock` — позначка наявності товару: крапка плюс слово.

**Коли брати.** У рядку списку й на картці товару. Для статусів замовлення компонент не призначений.

**Що дає споживач.** Лише текст. Три формулювання зафіксовані: «Є на складі», «Мало», «Немає в нашому магазині». Інші слова не вигадуйте.

**Стани.** `.stock` — є, крапка кольору `--olive`. `.stock.low` — мало, текст і крапка `--warn`. `.stock.none` — немає, крапки нема, лишається слово.

**Токени.** `--olive`, `--warn`, `--text-2`, `--radius-pill`, `--space-6`.

**Правила.**
- Роблять: слово в кожному стані, крапка лише доповнює його.
- Роблять: `.stock.none` разом із кнопкою «Шукати на Prom» у рядку.
- Не роблять: статус одним кольором чи однією крапкою.
- Не роблять: червоний для відсутнього товару, це не помилка.
- Не роблять: кількість штук у цій позначці; кількість показує окремий елемент поруч.
