# Статті в MDX

Статті бази знань лежать у файлах MDX. Автор пише звичайний Markdown і ставить кілька власних компонентів; збірка перетворює це на розмітку з класами системи. Нижче — що у що перетворюється. Жоден елемент статті не має власних кольорів чи розмірів: усе береться з токенів.

## Поля на початку файла

```mdx
---
title: Як підібрати LiPo до моторів 2207
lead: Кількість банок, ємність, струмовіддача й роз'єм для рами 5 дюймів.
updated: 2026-11-18
tags: [Живлення, LiPo, 5 дюймів]
---
```

З цих полів складається `ArticleHeader`. Час читання рахує збірка. Надзаголовка, автора й версії в шапці немає.

## Стандартний Markdown

| У файлі | Розмітка й клас | Компонент |
| --- | --- | --- |
| Абзац, `**жирний**`, посилання | `p`, `strong`, `a.link` у `.prose` | Prose |
| `# Заголовок` | не вживається: `h1` ставить шапка статті | ArticleHeader |
| `##`, `###`, `####` | `h2`, `h3`, `h4` з `id` та `a.anchor` | Headings |
| `` `код` `` у реченні | `code` | Code |
| Блок ```` ``` ```` з мовою й `title="…"` | `figure.codeblock` > `.codeblock-head` + `pre > code` | CodeBlock |
| `![alt](шлях "Підпис")` | `figure.pic` > `img` + `figcaption`; без файла — `.plate` | Image |
| `> цитата` | `blockquote`, джерело у `footer` | Quote |
| `- пункт`, `1. пункт`, вкладені | `ul`, `ol` у `.prose`; другий рівень — кружечок і «а)» | Lists |
| `- [ ]`, `- [x]` | `ul.checks` > `li > label > input[type=checkbox]` | Lists |
| `---` | `hr` | Lists |
| `[^1]` і `[^1]: текст` | `sup.fn > a` і `section.footnotes > ol`, зворотне `a.fn-back` | Footnotes |
| Таблиця з `\|` | `.tbl-wrap > table.tbl` | Table |

Елементи, яких у системі немає: сирий HTML зі `style`, вбудовані `iframe` поза `Media`, заголовки п'ятого й шостого рівня, зображення як посилання-банер. Збірка зупиняється з помилкою, якщо їх зустріне.

## Компоненти MDX

| У файлі | Розмітка й клас | Компонент |
| --- | --- | --- |
| `<ProductInline sku="…" />` | `div.product` > `.product-main` + `.product-buy` (`.stock`, `.price`, `.btn`) | ProductInline |
| `<Callout type="note">` | `div.note[role=note]` із заголовком «Примітка» | Callout |
| `<Callout type="warn">` | `div.note.warn`, «Технічні вимоги» | Callout |
| `<Callout type="danger">` | `div.note.danger`, «Небезпечно» | Callout |
| `<Steps>` + `<Step title="…">` | `ol.steps > li > h3` + вміст | Steps |
| `<Tabs label="…">` + `<Tab title="…">` | `.tabs` > `.tablist[role=tablist]` > `button.tab[role=tab]`; `.tabpanel[role=tabpanel]` | Tabs |
| `<Details summary="…">` | `details.details > summary` + `.details-body` | Details |
| `<Download href title />` | `a.file[download]` у `.files`; тип у `code`, розмір числом | Download |
| `<PinoutTable caption columns rows />` | `.tbl-wrap > table.tbl.pinout`, вивід у `td.pin` | PinoutTable |
| `<Calc>` + `<CalcLine>`, `<Value>`, `<Result>` | `figure.calc > .calc-line > .calc-step > .calc-term` | Calc |
| `<Term>РЕБ</Term>` | `span.term > abbr[tabindex=0]` + `span.term-tip[role=tooltip]` | Term |
| `<Video src poster title />` | `figure.pic > .video > button.video-play`, після натискання `video[controls]` | Media |
| `<Gallery>` + `<Photo src alt caption />` | `ul.gallery > li > a > img + span` | Media |
| `<Figure>` з SVG і позиціями | `figure.fig` + `ul.poslist` | Figure |

Компонент не приймає пропів `className` і `style`. Якщо статті бракує елемента, його спершу додають до системи, а тоді вживають.

## Нерозривний пробіл ставить збірка

Автор набирає звичайний пробіл: `22,2 В`, `1 380 ₴`. Під час збірки він стає нерозривним (U+00A0), тож число ніколи не лишається в кінці рядка без одиниці. Правило спрацьовує в чотирьох випадках:

1. **Число й одиниця:** `22,2 В`, `130 А`, `1300 мА·год`, `5,8 ГГц`, `16 мм`, `32,5 г`, `20–30 %`, `−10 °C`, `6 хв`, `240 КБ`, `4 шт.`
2. **Розряди тисяч:** `1 380`, `12 500`.
3. **Число й гривня:** `1 380 ₴`.
4. **Множення розмірів:** `16 × 16 мм` — пробіли обабіч `×` теж нерозривні.

Перелік одиниць, які збірка впізнає: В, мВ, А, мА, А·год, мА·год, Вт, Вт·год, Ом, мОм, мкФ, Гц, кГц, МГц, ГГц, дБ, дБм, мм, см, м, км, г, кг, с, мс, хв, год, °C, %, ₴, КБ, МБ, ГБ, шт., об/хв, дюймів. Нову одиницю додають до цього переліку, а не набирають `&nbsp;` у статті.

Чого збірка не чіпає:

- вміст `code`, блоків коду й `td.pin`: там пробіли лишаються як є;
- маркування латиницею без пробілу: `6S`, `XT60`, `1950KV`, `100C`, `12AWG`;
- адреси посилань і значення пропів.

Заразом збірка міняє прямий апостроф на `’` у словах (`роз'єм` → `роз’єм`), дефіс між числами на тире діапазону (`20-30` → `20–30`) і дефіс-мінус перед числом зі знаком на `−`. Десятковий розділювач — кома; крапку в `21.0` поза кодом збірка не виправляє, а зупиняється з попередженням, бо це може бути номер версії.

## Перевірка статті перед публікацією

- Кожне зображення має `alt` і підпис; кожне відео — текстовий опис.
- На екрані одна оливова кнопка: щонайбільше один `ProductInline` з `primary`.
- «Технічні вимоги» й «Небезпечно» не сховані в `Details`, виносках чи вкладках.
- Mono — лише коди, позначення й виміри; назви товарів і слова набрані звичайним шрифтом.
- Вигаданих цін та артикулів немає: `ProductInline` бере дані з каталогу за `sku`.
