`.pic` — зображення з підписом у тексті статті: фото деталі або знімок екрана конфігуратора.

**Коли брати.** Коли читач має побачити предмет або екран. Креслення з розмірами й позиціями — це `Figure`; кілька фото одного процесу — галерея з `Media`.

**Що дає автор.** У Markdown: `![Опис для тих, хто не бачить](шлях "Підпис")`. Опис стає `alt`, підпис — `figcaption`. Клас `.narrow` обмежує ширину 420px для вертикальних і дрібних фото. Доки файлу немає, збірка ставить плиту `.plate` (4:3) або `.plate.wide` (16:9) з чесним написом «Фото ще не додано».

**Стани.** Завантажено; завантаження — `.skel` тих самих пропорцій; помилка — `.pic-err` зі словом, причиною й посиланням на файл. Підпис лишається під блоком у кожному стані.

**Токени.** `--radius-lg`, `--line`, `--plate`, `--on-plate`, `--fill`, `--fill-strong`, `--text-2`, `--danger`, `--space-8`, `--space-12`, `--space-16`.

**Правила.**
- Можна: підпис, що каже, на що дивитися: «Serial Rx увімкнено на `UART2`».
- Можна: знімок екрана з темою конфігуратора як є, без обробки.
- Не можна: стокове чи згенероване фото замість справжнього; краще плита-заповнювач.
- Не можна: текст інструкції лише на зображенні, тінь і рамка довкола фото.
