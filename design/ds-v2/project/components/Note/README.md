`.note` — виділений блок тексту всередині статті; `.note.warn` додає заголовок із попередженням.

**Коли брати.** `.note` для зауваження, яке не блокує читання. `.note.warn` для технічних вимог, недотримання яких пошкодить обладнання. Не використовуйте для повідомлень про помилку в інтерфейсі: це роль рядка помилки з `States`.

**Що дає споживач.** Текст. Для `.warn` перший дочірній елемент — `<b>` з іконкою `.icon` і словом «Технічні вимоги»; далі текст.

**Стани.** Звичайний: фон `--fill`. Попередження: заголовок кольору `--warn`, поруч іконка трикутника, тож сигнал несе слово й форма, а не колір.

**Токени.** `--fill`, `--radius-lg`, `--space-12`, `--space-16`, `--space-4`, `--warn`.

**Правила.**
- Роблять: один блок на один висновок, короткий текст.
- Роблять: числа з нерозривним пробілом: «3,5 В».
- Не роблять: рамку чи кольорову смугу збоку.
- Не роблять: `.warn` без заголовка-слова; не ставте кілька блоків підряд.
