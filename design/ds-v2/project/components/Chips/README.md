Чипи `.chips` з `.chip` — це набір кнопок для фільтра за однією категорією.

Використовуйте, коли варіантів небагато і треба швидко звузити список: «Акумулятори», «Роз'єми». Для довгих списків беріть `.fld` з `select`, для вибору кількох значень беріть окремі прапорці.

Споживач дає текст кожного чипа і `aria-pressed="true"` або `"false"`. Обгортці `.chips` додайте `role="group"` та `aria-label` («Категорія»). Скрипт сам тримає вибраним один чип.

Стани: звичайний, `:hover`, фокус (кільце 2px `olive-ink`), вибраний `[aria-pressed="true"]` (інверсна заливка `text` на `bg`). Вибір видно не лише кольором: змінюється контраст і значення `aria-pressed`. Нижче 760px чип росте до `control-touch`.

Токени: `control`, `radius-md`, `space-6`, `space-12`, `fill`, `fill-strong`, `text`, `bg`, `olive-ink`.

- Завжди давайте чип «Усі», щоб фільтр можна було скинути.
- Не вмикайте вибраним кілька чипів у одній групі.
- Не ставте оливкову заливку на чип: олива зарезервована для головної дії.
- Тримайте назви короткими, до двох слів.
