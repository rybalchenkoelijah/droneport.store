`.file` — рядок файла для завантаження: назва, тип, розмір і дія; кілька рядків збирає `.files`.

**Коли брати.** Для файла, який читач забере із собою: пам’ятка PDF для друку, модель STL, файл параметрів або дамп налаштувань. Посилання на іншу сторінку — це `.link`; відео й фото показує `Media`.

**Що дає автор.** У MDX: `<Download href="/files/preflight.pdf" title="Пам’ятка: перевірки перед вильотом" />`. Тип і розмір збірка читає з файла сама й пише як `code` та число з одиницею: «`PDF` · 240 КБ». Проп `note` додає коротке пояснення після розміру, наприклад «текстовий файл».

**Стани.** Звичайний; наведення — `--fill` на весь рядок; фокус — кільце довкола рядка; недоступний — `aria-disabled="true"`, колір `--text-3`, слово «Недоступний» і причина замість розміру. Натискається весь рядок, його висота не менша за 44px. Між сусідніми рядками одна лінія `--line`.

**Токени.** `--fill`, `--line`, `--text`, `--text-2`, `--text-3`, `--radius-md`, `--icon`, `--icon-sm`, `--space-6`, `--space-8`, `--space-12`.

**Правила.**
- Можна: назва каже, що у файлі й для чого він.
- Можна: розмір із нерозривним пробілом і комою: «1,8 МБ».
- Не можна: приховувати тип і розмір — у полі трафік рахують.
- Не можна: оливова кнопка в рядку та назва «Завантажити файл» без предмета.
