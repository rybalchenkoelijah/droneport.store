# Дизайн Дронопорту

Усе, що визначає вигляд сайту, лежить тут і пов'язане в один ланцюжок. Зміна вгорі ланцюжка сама доходить до низу: нічого не копіюється руками.

```
system/project/        джерело дизайн-системи: tokens.json, components/bundle.css, components/bundle.js
        │  node design/build.mjs
        ▼
system/droneport.css   ОДИН файл дизайн-системи: токени обох тем і стилі всіх компонентів (генерується)
        │  підключається кожною сторінкою
        ▼
blocks/*.html          блоки: ліва панель, верхня смуга, пошук, права панель, товар, файл, іконки
        │  <!-- @block назва параметр="…" -->
        ▼
pages/*.html           сторінки: складаються з блоків і компонентів системи
        │
        ▼
dist/                  зібрані сторінки для перегляду (не в git)
```

## Команди

```bash
node design/build.mjs            # зібрати все й перевірити
node design/build.mjs --watch    # перезбирати після кожної зміни
node design/system/tools/shot.mjs            # знімки прев'ю компонентів у двох темах
```

Після збірки відкрийте `design/dist/index.html`.

## Що де міняти

| Хочу змінити | Файл | Що оновиться саме |
| --- | --- | --- |
| Колір, відступ, радіус, шрифт | `system/project/tokens.json` | `droneport.css`, усі блоки й сторінки |
| Вигляд компонента (кнопка, примітка, таблиця) | `system/project/components/bundle.css` | усі блоки й сторінки, де він ужитий |
| Поведінку (вкладки, копіювання, тема, меню) | `system/project/components/bundle.js` | усі сторінки |
| Ліву панель, пошук, рядок товару | `blocks/<назва>.html` | усі сторінки з цим блоком |
| Вміст однієї сторінки | `pages/<назва>.html` | лише вона |

`system/droneport.css` і `system/project/tokens.css` руками не правлять: їх пише збірка.

## Правила, які перевіряє збірка

- У блоках і сторінках немає `<style>`, власних `<link rel="stylesheet">`, сирих кольорів та inline-стилів (виняток — змінні стану на кшталт `style="--_progress:40%"`).
- Кожен клас у блоці чи сторінці має існувати в `droneport.css`. Якщо компонент у системі перейменували або прибрали, збірка назве кожне місце, де він ще вжитий.
- Блок, якого немає, і `current="…"`, якого немає в навігації, зупиняють збірку.
- Система сама перевіряє контраст в обох темах, поле `usage` в кожного токена й наявність прев'ю та README у компонентів.

Якщо сторінці бракує стилю, його додають у систему (`bundle.css`), а не в сторінку.

## Блоки

Блок — файл `blocks/<назва>.html`; перший рядок-коментар описує його й параметри. Виклик: `<!-- @block product name="…" sku="…" price="1&nbsp;640" -->`, у тексті блока параметр стоїть як `{{name}}`. Блок може викликати інші блоки. Іконки — теж блоки: `<!-- @block icons/doc class="sm" -->`.

## Сторінки

Перший рядок: `<!-- @page title="…" current="id-пункту-меню" -->`. `current` позначає поточний пункт лівої панелі. Далі — розмітка з блоків і класів системи. Збірка сама додає `<head>`, `droneport.css` і `droneport.js`.
