# Дизайн Дронопорту

Усе, що визначає вигляд сайту, лежить тут і пов'язане посиланнями, як компоненти у Figma. Копій немає, збірки немає, команд немає: сторінка під час відкриття сама бере актуальні токени, стилі й блоки. Змінили файл — оновили вкладку — зміна всюди.

```
system/droneport.js                    єдине підключення системи: один рядок у кожній сторінці
   ├─ читає  system/project/tokens.json            кольори обох тем, шрифти, відступи, радіуси, розміри
   ├─ читає  system/project/components/bundle.css  вигляд компонентів
   ├─ читає  system/project/components/bundle.js   поведінка: вкладки, копіювання, тема, меню
   └─ підставляє блоки з blocks/*.html

blocks/*.html      блоки: ліва панель, верхня смуга, пошук, права панель, товар, файл, іконки
*.html             сторінки: index.html, article.html, catalog.html
```

## Що де міняти

| Хочу змінити | Файл | Де з'явиться |
| --- | --- | --- |
| Колір, відступ, радіус, шрифт | `system/project/tokens.json` | у всіх компонентах, блоках і сторінках |
| Вигляд компонента (кнопка, примітка, таблиця) | `system/project/components/bundle.css` | всюди, де компонент ужитий |
| Поведінку (вкладки, тема, меню) | `system/project/components/bundle.js` | на всіх сторінках |
| Ліву панель, пошук, рядок товару | `blocks/<назва>.html` | на всіх сторінках із цим блоком |
| Вміст однієї сторінки | `<сторінка>.html` | лише на ній |

## Як сторінка під'єднана

У `<head>` один рядок, більше жодних стилів чи скриптів:

```html
<script src="system/droneport.js" data-current="a-lipo-2207"></script>
```

`data-current` — це `data-id` пункту лівої панелі, який треба позначити поточним.

Блок викликається коментарем: `<!-- @block product name="…" sku="…" price="1&nbsp;640" -->`. У файлі блока параметр стоїть як `{{name}}`. Блок може викликати інші блоки; іконки — теж блоки: `<!-- @block icons/doc class="sm" -->`. Перший рядок-коментар у файлі блока описує його й параметри.

## Сторінка сама каже, коли щось розійшлося

Якщо блок чи сторінка вживає клас, якого в системі вже немає, викликає блок, якого немає, або несе власний `<style>`, у лівому нижньому куті з'являється плашка з переліком розбіжностей. Тож після перейменування компонента видно кожну сторінку, де лишилася стара назва.

Якщо сторінці бракує стилю, його додають у систему (`bundle.css`), а не в сторінку.

## Обмеження

- Сторінки мають відкриватися з вебсервера чи хостингу (опублікований артефакт, GitHub Pages, будь-який статичний сервер). Подвійний клік по файлу не спрацює: браузер не дає файлам читати сусідні файли.
- Це макети для погодження дизайну. Тема OpenCart на живому сайті до них ще не під'єднана.
