`.plate` — світла плита 4:3 для фото товару; `.plate.sm` — мініатюра 44 × 44.

**Коли брати.** Для фото на білому тлі на картці товару й у рядку списку. Для креслень є `Figure`.

**Що дає споживач.** Зображення `img` усередині (воно вписується через `object-fit: contain`). Без фото плита лишається порожньою: у ній стоїть підпис моноширинним шрифтом, наприклад розмір статора «2207 · 1950KV».

**Стани.** Із фото; порожня з підписом. Плита лишається світлою в обох темах, щоб фото на білому тлі не мало темної рамки.

**Токени.** `--plate`, `--line`, `--line-w`, `--radius-lg`, `--radius-md`, `--bg`, `--text-2`.

**Правила.**
- Роблять: підпис у порожній плиті лише кодом чи виміром.
- Роблять: `alt` з назвою товару на кожному `img`.
- Не роблять: бейджі «ХІТ», знижки й рейтинг на плиті.
- Не роблять: свою заливку чи тінь; фон і лінію задає клас.
