Логотип «Дронопорт»: коло кольору `brand` і назва, переведена в контури.

- `logo-mark.svg` — знак окремо, для значка сайту й місць до 32px.
- `logo-lockup.svg` — знак із назвою для світлого тла (`bg`, `bg-side`).
- `logo-lockup-dark.svg` — те саме для темного тла.

Колір знака однаковий в обох темах і не змінюється. Навколо логотипа лишайте вільне поле не менше висоти знака. Не розтягуйте, не перефарбовуйте, не ставте на фото. У верхній смузі лівої панелі стоїть `logo-lockup.svg` заввишки `logo`: знак і назва разом, як одне посилання на головну. Назву шрифтом не набирають — літери беруться з файлу; у розмітці колір назви береться з `text`, тож окремий темний файл потрібен лише поза інтерфейсом. У вузьких місцях лишається сам знак.
