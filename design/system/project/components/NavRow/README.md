`.row` у `.nav` і `.navlist` — рядок бічної навігації з іконкою, назвою та другорядними елементами.

Використовуйте для розділів, статей і закріплених пунктів у лівій панелі. Для дій на сторінці беріть `.btn`, для вкладок усередині контенту — `.chip`.

Ви додаєте: `<a>` або `<button>` із `class="row"`, іконку `.icon`, текст у `<span>`, за потреби `<small>` (лічильник) чи `<kbd>`, кнопку `.tail` з `aria-label`. Групу робіть кнопкою `.grp` з `aria-expanded`, а підсумковий рядок — `.user` з `.badge`.

Стани. Наведення дає тло `fill`. Вибраний пункт має `aria-current="page"` і тло `fill-strong`. Вимкнений має `aria-disabled="true"` і колір `text-3`. `.tail` з'являється при наведенні або фокусі всередині рядка, а `aria-pressed="true"` залишає його видимим.

Токени: `row`, `space-8`, `radius-md`, `fill`, `fill-strong`, `text-2`, `text-3`, `line`, `control-touch`.

Правила:
- Вибраний пункт — лише тінт `fill-strong`, ніколи суцільна темна заливка.
- Між рядками не ставте роздільників.
- Другорядні дії ховайте в `.tail`, не показуйте постійно.
- Нижче 760px рядок підростає до `control-touch` (44px), а панель стає висувною над `scrim`.
