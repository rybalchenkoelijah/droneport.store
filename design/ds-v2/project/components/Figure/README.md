`.fig` — підписане креслення з нумерованими позиціями; поруч іде `.poslist`.

**Коли брати.** Для справжнього креслення виробу: кріплення мотора, габарити. Для ілюстрацій і схем без розмірів `.fig` не підходить: умовності креслення діють лише тут.

**Що дає споживач.** `svg` з `viewBox` і `aria-label`, шляхи з класами `c` (контур), `ax` (штрихпунктирна вісь), `dm` (розмірна лінія), `mk` (маркер), `text`; `figcaption`; список `.poslist` з `id="poz-1"` і далі.

**Стани.** Маркер — посилання `<a href="#poz-1">`; наведення дає фон `--fill-strong`, а рядок-ціль підсвічується через `:target`.

**Токени.** `--text`, `--text-2`, `--bg`, `--line-dwg-main`, `--line-dwg-dim`, `--marker`, `--font-mark`, `--fill`.

**Правила.**
- Роблять: розміри в міліметрах, підпис «Вид знизу».
- Роблять: номер маркера збігається з `.pos` у списку.
- Не роблять: кольорові лінії й заливки в кресленні.
- Не роблять: штрихпунктир чи розмірні лінії поза `.fig`.
