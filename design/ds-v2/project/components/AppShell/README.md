`.app` — каркас із трьох зон: бічна панель, основна зона й права панель на спільному тлі.

Використовуйте як оболонку кожної сторінки Дронопорту: `.side` для навігації, `.main` для контенту, `.panel` для зв'язаних даних. Для окремих модальних екранів він не потрібен.

Ви додаєте: корінь `.app` із заданою висотою, у `.side` — `.bar`, `.nav`, `.navlist`, `.user`; у `.main` — `.bar`, `.scroll > .col`, `.dock` із `.search` та `.status`; у `.panel` — секції `.sec`. Модифікатори `.noside` і `.nopanel` прибирають зону.

Стани. Зони мають одне тло, а розділяє їх лише лінія `line` 1px. Нижче 1100px права панель опускається під контент. Нижче 760px `.side` стає висувною шухлядою над `scrim`, а цілі дотику зростають до `control-touch` (44px).

Токени: `bg`, `bg-side`, `side`, `panel`, `bar`, `measure`, `line`, `scrim`, `control-touch`.

Правила:
- Не фарбуйте зони в різні кольори й не додавайте тіней між ними.
- Текст у `.col` не ширший за `measure`.
- Не ховайте пошук у шапку: він живе в `.dock`.
- Висоту корінь отримує ззовні, інакше сітка схлопнеться.
