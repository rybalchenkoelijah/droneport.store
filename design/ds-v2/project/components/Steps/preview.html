Процедура: крок із текстом, із кодом, із зображенням і з приміткою

  1. Зніміть пропелери

    Мотори перевіряють лише без пропелерів, навіть якщо дрон стоїть на стенді.

  2. Увімкніть протокол регуляторів

    У вкладці CLI введіть команди й дочекайтеся перезавантаження контролера.

  3. Перевірте напрямок обертання

    У вкладці Motors по черзі дайте кожному мотору мінімальний газ і порівняйте напрямок зі схемою.

  4. Від’єднайте акумулятор

    Технічні вимоги

    Ставте пропелери лише після того, як акумулятор від’єднано.

Короткі кроки без заголовків

  1. Підключіть контролер кабелем USB.

  2. Відкрийте вкладку CLI й введіть diff all.

  3. Збережіть виведений текст у файл.
