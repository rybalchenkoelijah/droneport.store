`.sec` — секція правої панелі із заголовком і списком рядків `.kv`.

Використовуйте для пов'язаних товарів, метаданих статті, підсумку запиту. Для головного контенту беріть `.col`, для довгих списків із фото — `.items`.

Ви додаєте: `<h2>` із необов'язковим лічильником у `<small>`, рядки `.kv` (іконка, текст або `<a>`, ціна в `<small>`, `.ib.sm` для додавання з `aria-label`), блок `.total`, кнопку `.btn.primary.block`. Порожню секцію заповніть `<p class="empty">` з підказкою, що робити далі.

Стани. Наступна `.sec` відділяється лінією `line` 1px, без зайвих рамок. Посилання в `.kv` підкреслюється при наведенні. Довгий текст обрізається трикрапкою. Кнопка `.ib.sm` має колір `text-2`, при наведенні `text` і тло `fill`.

Токени: `space-12`, `space-8`, `line`, `text-2`, `control`, `fill`, `olive`, `on-olive`.

Правила:
- Секції розділяйте лише лінією, без карток і тіней.
- Одна `.btn.primary` на панель.
- Лічильник показуйте числом, а не словом.
- Порожній стан завжди пояснюйте, не залишайте порожню секцію.
- Нижче 1100px панель опускається під контент, а нижче 760px рядки досягають `control-touch` (44px).
