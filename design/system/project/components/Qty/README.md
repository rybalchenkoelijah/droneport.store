Лічильник `.qty` змінює кількість товару кнопками «−» та «+».

Використовуйте в кошику й на картці товару. Для довільного числа понад десятки беріть `.fld` з числовим полем.

Споживач дає дві кнопки з іконками `minus` і `plus` та `aria-label` («Менше», «Більше»), а також `output` з поточним числом і `aria-label="Кількість"`. Скрипт оновлює `output`, вимикає мінус на 1 і плюс на максимумі зі складу.

Стани: звичайний, `:hover` кнопки, фокус (кільце 2px `olive-ink`), мінус `:disabled` на 1. Нижче 760px кнопки ростуть до `control-touch` (44px). Число виведено з `tabular-nums`, тож ширина не стрибає.

Токени: `space-2`, `radius-sm`, `fill`, `text`, `text-2`, `text-3`, `olive-ink`.

- Вимикайте мінус на 1, а не дозволяйте нуль: для видалення дайте окрему кнопку.
- Не показуйте обмеження лише сірим кольором: поруч напишіть «Мало» чи «Є на складі».
- Не ховайте `output` у `input`, щоб не втратити озвучення зміни.
- Не ставте `.qty` без підпису товару поруч.
