`.tabs` — вкладки для варіантів однієї інструкції: той самий крок для Betaflight, INAV чи ArduPilot.

**Коли брати.** Коли читачеві потрібен один варіант із кількох рівноцінних і решта лише заважає. Якщо варіанти треба порівняти, покажіть їх таблицею. Послідовні частини статті вкладками не роблять: читач їх не знайде пошуком по сторінці.

**Що дає автор.** У MDX: `<Tabs label="Прошивка">` і всередині `<Tab title="Betaflight">вміст</Tab>`. Збірка створює `.tablist` з `role="tablist"` та `aria-label`, кнопки `.tab` з `role="tab"`, `aria-selected`, `aria-controls` і панелі `.tabpanel` з `role="tabpanel"`, `aria-labelledby`, `tabindex="0"`.

**Стани.** Вкладка: звичайна (`--text-2`), наведення `--fill`, фокус (кільце всередині кнопки), обрана — відтінок `--fill-strong` і текст `--text`, вимкнена `--text-3`. Клавіатура: Tab входить на обрану вкладку, стрілки вліво й управо перемикають по колу, Home та End ведуть до першої й останньої, наступний Tab переходить у панель. На телефоні висота вкладки 44px, довгий ряд прокручується вбік.

**Токени.** `--fill`, `--fill-strong`, `--text`, `--text-2`, `--text-3`, `--line`, `--radius-md`, `--control`, `--control-touch`, `--space-2`, `--space-6`, `--space-12`, `--olive-ink`.

**Правила.**
- Можна: назва вкладки — власна назва прошивки чи моделі, одне-два слова.
- Можна: той самий порядок вкладок у всій статті.
- Не можна: суцільна темна заливка чи олива на обраній вкладці.
- Не можна: більше п’яти вкладок і вкладки всередині вкладок.
