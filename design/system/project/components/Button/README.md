Кнопка `.btn` запускає дію: додати в кошик, шукати, очистити.

Використовуйте для дій на сторінці. Для переходу на іншу сторінку беріть `.link`, для дії лише з іконкою беріть `.ib`.

Споживач дає текст кнопки (дієслово: «У кошик», «Шукати на Prom») і атрибут `type`. Для `.is-loading` додайте `aria-busy="true"` та `aria-label`, бо текст прозорий.

Стани: звичайна, `:hover`, фокус (`:focus-visible`, кільце 2px `olive-ink` через `line-focus`), натиснута (`:active`), `:disabled` або `aria-disabled="true"`, `.is-loading`. Варіанти: `.primary`, `.ghost`, `.danger`, `.block`, `.lg`. На ширині до 760px кнопка росте до `control-touch` (44px).

Токени: `control`, `control-touch`, `radius-md`, `space-12`, `fill`, `fill-strong`, `olive`, `on-olive`, `danger`, `text-3`, `olive-ink`.

- Робіть на екрані одну заповнену оливкову `.btn.primary`.
- Не передавайте стан лише кольором: для `.danger` пишіть у тексті, що саме буде видалено.
- Не вимикайте кнопку без пояснення поруч, чому дія недоступна.
- Не ставте `.link` замість кнопки для дії, що змінює дані.
