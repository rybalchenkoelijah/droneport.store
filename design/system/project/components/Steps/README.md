`.steps` — нумерована процедура: кожен крок має номер, заголовок і власний вміст.

**Коли брати.** Для послідовності, де порядок важить і крок потребує пояснення, коду чи знімка: перший запуск моторів, прив’язка приймача, прошивка. Три короткі дії без пояснень лишаються звичайним нумерованим списком. Перелік перевірок без порядку — `.checks` із `Lists`.

**Що дає автор.** У MDX: `<Steps>` і всередині `<Step title="Зніміть пропелери">вміст</Step>`. Заголовок стає `h3`, номер ставить лічильник CSS. У кроці можна абзаци, `CodeBlock`, `Image`, `Callout`, `Calc`. Без `title` крок складається лише з тексту.

**Стани.** Процедура статична: стану «виконано» немає, бо стаття його не зберігає. Тонка лінія `--line` веде від номера до наступного кроку; після останнього її немає.

**Токени.** `--fill-strong` (тло номера), `--radius-sm`, `--line`, `--line-w`, `--text`, `--space-4`, `--space-6`, `--space-12`, `--space-16`.

**Правила.**
- Можна: заголовок-дія в наказовому способі: «Від’єднайте акумулятор».
- Можна: попередження всередині того кроку, якого воно стосується.
- Не можна: номер у колі з обвідкою — це позиційний маркер креслення `.pos`.
- Не можна: дві дії в одному кроці та вкладені `Steps`.
