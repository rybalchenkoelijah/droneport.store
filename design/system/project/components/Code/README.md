`code` — рядковий чип для артикула, позначення або виміру всередині речення, і `mark` для збігу пошуку.

**Коли брати.** Для артикулів (`TM-F60V-1950`), позначень (`6S`, `XT60`, `1950KV`) і виміряних розмірів (`16 × 16 мм`). Для слів, назв товарів і виробників не брати: вони лишаються шрифтом `--font-text`.

**Що дає споживач.** Лише текст усередині `code` або `mark`. Чип не переноситься на новий рядок.

**Стани.** Чип один. `mark` підсвічує збіг пошуку і може стояти як на звичайному слові, так і всередині `code`.

**Токени.** `--font-mark` (Martian Mono, стиснення 87,5 %), `--fill`, `--radius-xs`, `--space-2`, `--space-4`, `--hit`.

**Правила.**
- Роблять: один чип на одне позначення, нерозривний пробіл перед одиницею.
- Роблять: `mark` на слові «LiPo» в заголовку статті без `code`.
- Не роблять: `code` на «T-Motor», «акумулятор» чи цілому реченні.
- Не роблять: колір чи жирність поверх `mark`; підсвічування вже закладене.
