`.prose` — текст статті бази знань: заголовки, абзаци, списки й посилання в одній колонці.

**Коли брати.** Для будь-якого довгого тексту: стаття, опис товару, довідка. Для коротких підписів і пояснень у інтерфейсі `.prose` не потрібен.

**Що дає споживач.** Семантичну розмітку: `h1`, `h2`, `p`, `ul`, `ol`, `.link`, `code`. Ширину колонки задає контейнер: `max-width: var(--measure)`.

**Стани.** Посилання `.link` має наведення з підкресленням; окремих станів у тексту немає.

**Токени.** `--text`, `--text-2` (маркери списків), `--olive-ink` (посилання), `--space-12`, `--space-24`; розмір і інтервал — стилі `title`, `heading`, `body`.

**Правила.**
- Роблять: жирний вступ у пунктах списку («**Ємність:** …»); нерозривний пробіл між числом і одиницею, кома як десятковий роздільник, одиниці кирилицею: «22,2 В».
- Роблять: `code` лише для кодів, позначень і вимірів.
- Не роблять: рейтинги, значки «ХІТ», знижки в тексті.
- Не роблять: `h3` і глибша вкладеність; ділять статтю на `h2`.
