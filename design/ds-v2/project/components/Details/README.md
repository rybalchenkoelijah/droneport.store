`.details` — розкривний блок на нативному `<details>`: рядок-заголовок і прихований вміст.

**Коли брати.** Для матеріалу, потрібного не кожному: довгий дамп налаштувань, пояснення «чому так», відповіді на часті запитання. Технічні вимоги й небезпеку не згортають — це `Callout`, який видно одразу.

**Що дає автор.** У MDX: `<Details summary="Як порахувати тривалий струм">вміст</Details>`; проп `open` розкриває блок від початку. Збірка ставить у `<summary>` шеврон `.icon.sm` і загортає вміст у `.details-body`. Усередині можна абзаци, `CodeBlock`, таблицю, `Calc`.

**Стани.** Згорнутий; розгорнутий — шеврон повертається на 90°; наведення на рядок — `--fill`; фокус — кільце на `<summary>`. Enter і пробіл працюють без скриптів, пошук браузера по сторінці сам розкриває блок із збігом. Кілька блоків підряд ділять одну лінію `--line`. На телефоні рядок заввишки 44px.

**Токени.** `--line`, `--fill`, `--text-2` (шеврон), `--radius-md`, `--icon-sm`, `--space-4`, `--space-6`, `--space-8`, `--space-12`, `--control-touch`, `--dur-fast`.

**Правила.**
- Можна: заголовок, що каже, що всередині: питання або назва файлу.
- Можна: розкривати блок через `open`, коли стаття коротка.
- Не можна: ховати крок процедури чи попередження.
- Не можна: вкладати `Details` один в один і писати заголовок «Докладніше».
