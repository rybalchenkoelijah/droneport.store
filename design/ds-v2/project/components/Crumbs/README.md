`.crumbs` — рядок шляху до поточної сторінки з метаданими в кінці.

Використовуйте над заголовком статті або товару, щоб показати розділ і дати контекст: час читання, тег. Для переходу між сторінками одного рівня беріть `NavRow`, для заголовка зони — `TopBar`.

Ви додаєте: `<nav class="crumbs" aria-label="Шлях">`, посилання `<a>` для кожного кроку, між ними `.icon` із шевроном, поточну сторінку в `<span>` з `aria-current="page"`. Метадані — `<span>` з іконкою `.icon.sm` після останнього шеврона.

Стани. Посилання мають колір `text-2`, а при наведенні переходять у `text`. Поточна сторінка й метадані не клікабельні. На вузькій ширині рядок переноситься завдяки `flex-wrap`.

Токени: `text`, `text-2`, `space-6`, `space-16`, `icon-sm`.

Правила:
- Шеврон лише між кроками, не перед першим.
- Метадані короткі: одне-два слова з іконкою.
- Не підкреслюйте посилання постійно: достатньо зміни кольору.
- Не робіть поточну сторінку посиланням на саму себе.
- Шлях не довший за три кроки.
