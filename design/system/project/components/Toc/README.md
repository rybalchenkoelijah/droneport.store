`.toc` разом із `.read` і `.track` — зміст статті з індикатором прочитаного.

Використовуйте в правій панелі довгих статей, щоб орієнтуватися за заголовками. Для коротких текстів і для навігації між статтями він зайвий: беріть `NavRow`.

Ви додаєте: `.read` із заголовком `<b>` і відсотком у `<span>`, `.track` з `<i>`, ширину якого задаєте у `style="width:40%"` (за потреби додайте `role="progressbar"` та `aria-valuenow`), `<nav class="toc" aria-label="Зміст">` з посиланнями `<a>`. Поточний розділ позначте `aria-current="location"`.

Стани. Звичайне посилання має колір `text-2` і маркер `fill-strong`. Наведення дає колір `text`. Поточне посилання має колір `text` і маркер `olive`. Смуга прогресу плавно росте за `dur-base`.

Токени: `olive`, `fill-strong`, `text`, `text-2`, `space-8`, `radius-pill`, `dur-base`, `control-touch`.

Правила:
- Лише один `aria-current` на весь зміст.
- Назви пунктів короткі, щоб не переноситися.
- Не додавайте вкладені рівні: зміст плоский.
- Не ставте акцентну заливку на весь рядок, акцент лише на маркері.
- Нижче 1100px панель, а з нею й зміст, опускається під контент.
