Лінійні іконки на сітці 24px: лінія `line-icon`, без заливки. Файли намальовані чорним; у розмітці іконки вставляються вбудованим SVG з `stroke="currentColor"`, щоб брати колір тексту (`text` або `text-2`).

- `sec-*` — розділи бази знань і каталогу. Розділ має одну іконку всюди, де він згадується.
- `home`, `folder`, `doc`, `collapse`, `chevron-down` — навігація.
- `search`, `theme`, `cart`, `external`, `download` — дії.
- `warning` — заголовок примітки з технічними вимогами, завжди разом зі словом.
- `drawing` — позначає, що в матеріалі є креслення.

Розміри: `icon` 20px у навігації та кнопках-іконках, `icon-sm` 16px у правій панелі. Емодзі й символи юнікоду замість іконок не використовуються.
