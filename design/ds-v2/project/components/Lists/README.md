Вкладені списки, перелік перевірок `.checks` і горизонтальна лінія `hr` у `.prose`.

**Коли брати.** Вкладений список — коли пункт має власні підпункти; глибше другого рівня не йдіть. `.checks` — перелік, який читач проходить руками: перевірки перед вильотом, комплектність. Послідовність дій із поясненнями — це `Steps`. `hr` відділяє частини статті, які не мають власного заголовка.

**Що дає автор.** У Markdown: відступ для вкладення, `- [ ]` і `- [x]` для прапорців, `---` для лінії. Збірка обгортає прапорець і текст у `<label>`, тож натискається весь рядок.

**Стани.** Прапорець: порожній, наведення (межа `--text-2`, рядок на `--fill`), фокус, позначений (тло `--text`, галочка `--bg`), вимкнений, вимкнений із позначкою. Другий рівень: кружечок у маркованому списку, «а)», «б)» у нумерованому.

**Токени.** `--line-control` (межа прапорця, 3 : 1), `--text`, `--bg`, `--text-2`, `--text-3`, `--fill`, `--line`, `--radius-xs`, `--radius-md`, `--space-6`, `--space-8`, `--space-24`, `--control-touch`.

**Правила.**
- Можна: формулювати перевірку як факт, що його видно: «Антени прикручені».
- Можна: вимкнений пункт із поясненням у дужках, кого він стосується.
- Не можна: закреслювати позначений рядок і заливати прапорець оливою.
- Не можна: `hr` як прикраса перед кожним заголовком.
