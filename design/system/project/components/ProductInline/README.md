`.product` — товар магазину, вбудований у текст статті: назва, артикул, наявність, ціна й кнопка.

**Коли брати.** Там, де стаття називає конкретну деталь і читач може одразу її замовити. Для переліку категорії є `ListItem`; у реченні досить посилання `.link`.

**Що дає автор.** У MDX: `<ProductInline sku="LP-6S-1300-100" />`. Назву, категорію, ціну й наявність збірка та сайт беруть із каталогу за артикулом; автор їх не набирає. Проп `primary` робить кнопку оливовою — лише для одного товару на статтю.

**Стани.** «Є на складі» з кнопкою «У кошик»; «Мало»; після додавання кнопка «У кошику» на `--fill-strong` веде до кошика; запит — `.is-loading`; «Немає в нашому магазині» — `.product.off` без ціни, з кнопкою «Шукати на Prom»; завантаження — `.skel`; помилка — «Ціну не отримано» й «Спробувати ще раз», назва та артикул лишаються. На вузькій колонці наявність, ціна й кнопка переходять у другий рядок.

**Токени.** `--line`, `--text`, `--text-2`, `--fill`, `--fill-strong`, `--olive`, `--on-olive`, `--warn`, `--danger`, `--plate`, `--radius-md`, `--space-8`, `--space-12`, `--control`, `--control-touch`.

**Правила.**
- Можна: кілька товарів підряд — вони ділять одну лінію.
- Можна: артикул у `code`, ціна з табличними цифрами й нерозривним пробілом.
- Не можна: друга оливова кнопка на екрані, знижки, «ХІТ», рейтинг.
- Не можна: рамка з тінню довкола блока й статус без слова.
