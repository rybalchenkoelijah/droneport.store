`.items > .item` — рядок списку товарів або статей.

**Коли брати.** Для результатів пошуку, категорій і добірок «Що взяти». Для порівняння кількох полів потрібна `Table`.

**Що дає споживач.** Товар: `<b>` з назвою, `<small>` з `code` артикула й категорією, далі `.stock`, `.price` і `.btn` «У кошик». Стаття: `.item.two` — назва, розділ і час читання («6 хв»).

**Стани.** Звичайний; наведення дає фон `--fill` і ховає лінію рядка; `.item.off` — товару немає: назва сіріє, `.stock.none` з повним словом, кнопка «Шукати на Prom».

**Токени.** `--fill`, `--line`, `--text-2`, `--radius-md`, `--space-6`, `--space-8`, `--space-12`, `--control`.

**Правила.**
- Роблять: ціна з нерозривними пробілами: «1 380 ₴».
- Роблять: наявність завжди словом.
- Не роблять: рейтинги, знижки й мітки «ХІТ».
- Не роблять: код у `<b>` з назвою; артикул стоїть окремо в `<small>`.
