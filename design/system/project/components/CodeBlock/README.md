`.codeblock` — блок коду з рядком заголовка: назва файлу або мова й кнопка «Копіювати».

**Коли брати.** Для всього, що читач переносить у конфігуратор чи термінал: дамп CLI Betaflight, параметри ArduPilot, одна команда. Код усередині речення лишається за `code` з компонента Code. Дамп на сотні рядків згорніть у `Details`.

**Що дає автор.** У Markdown — блок із трьома зворотними лапками, мовою й необов’язковою назвою: ` ```ini title="diff.txt" `. Збірка додає рядок `.codeblock-head` (назва в `<b>`, мова в `<span>`, кнопка `.btn.ghost`) і `<pre tabindex="0" role="region" aria-label="…">`. Рядки-коментарі загортаються в `.cm`.

**Стани.** Кнопка: звичайна, наведення `--fill`, фокус, «Скопійовано» на дві секунди, помилка зі словами, що робити далі. Блок `pre` отримує фокус з клавіатури, щоб довгий рядок можна було прокрутити стрілками; кільце `--olive-ink` лягає всередину блока.

**Токени.** `--fill`, `--line`, `--radius-lg`, `--text-2`, `--font-mark`, `--space-6`, `--space-12`, `--space-16`, `--olive-ink`.

**Правила.**
- Можна: приглушувати коментарі кольором `--text-2`.
- Можна: довгий рядок прокручувати всередині блока; сторінка вбік не їде.
- Не можна: різнокольорове підсвічування синтаксису.
- Не можна: переносити рядки коду й вставляти в блок знімок екрана з текстом.
