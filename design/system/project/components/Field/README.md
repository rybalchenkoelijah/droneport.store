Поле форми `.fld` поєднує мітку, елемент введення і підказку.

Використовуйте для введення тексту, вибору зі списку й коментаря. Для пошуку беріть `.search`, для кількості беріть `.qty`.

Споживач дає `label` з `for`, елемент `input`, `select` або `textarea` з тим самим `id`, і `small` з підказкою. Помилка: клас `.fld.err`, `aria-invalid="true"` на елементі та `aria-describedby`, що вказує на `small` з текстом помилки.

Стани: звичайне, фокус (кільце 2px `olive-ink`), помилка, `:disabled` (фон `fill`, текст `text-3`). Помилка не лише червона: її називає текст під полем. Окремого стану `:hover` у полі немає.

Токени: `control-field`, `radius-md`, `line-control`, `line-w`, `space-6`, `space-12`, `danger`, `text-2`, `text-3`, `fill`, `olive-ink`.

- Пишіть, що не так і як виправити: «Артикул не знайдено. Додайте дефіси, як на наклейці».
- Не замінюйте мітку плейсхолдером: він зникає при введенні.
- Не пишіть «Невірне значення» без пояснення.
- Не вимикайте поле без підказки, коли воно стане доступним.
